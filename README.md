# The Little Tibet — Premium Balti Family Restaurant Website

Static HTML/CSS/Vanilla JavaScript website for The Little Tibet, Skardu.

## Run
Open `index.html` directly or use VS Code Live Server. Suitable for Netlify, GitHub Pages and Vercel static hosting.

## Pages
index.html, menu.html, pricing.html, about.html, gallery.html, contact.html

## Content notes
- Address and phone use the supplied/current business listing details.
- Current structured listing hours: Mon–Thu/Sun 9 AM–9 PM, Fri 9 AM–5 PM, Sat 9 AM–10 PM; confirm before visiting.
- Public listing rating/review count are not used as fake testimonials.
- Pricing is explicitly labelled estimated visitor-reported range, not an official tariff.
- Menu prices are not invented.
- Gallery images are generic demo images and must be replaced with original restaurant photos before launch.
- Social links are placeholders and must be replaced with official profiles.
